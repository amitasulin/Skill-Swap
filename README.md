# Skill Swap - החלפת מיומנויות

פלטפורמה להחלפת מיומנויות המאפשרת לאנשים ללמד וללמוד זה מזה ללא עלות, באמצעות מערכת התאמות מבוססת AI.

## תכונות עיקריות

### Core Features (MVP)
- ✅ יצירת פרופיל משתמש עם מיומנויות ללמד וללמוד
- ✅ מערכת התאמות AI חכמה
- ✅ ממשק התאמות בסגנון Tinder
- ✅ מערכת צ'אט פנימית
- ✅ קביעת פגישות ושיעורים
- ✅ מעקב שיעורים ודירוגים

### Advanced Features (V2)
- 🔄 AI Lesson Planner - תוכניות לימוד מותאמות אישית
- 🔄 מערכת מוניטין מתקדמת עם תגיות ו-badges
- 🔄 התאמות קבוצתיות

## טכנולוגיות

- **Frontend**: Next.js 14 (App Router)
- **Styling**: TailwindCSS
- **State Management**: Zustand עם Local Storage persistence
- **Icons**: Lucide React
- **TypeScript**: Full type safety

## התקנה והרצה

### דרישות מוקדמות
- Node.js 18+ 
- npm או yarn

### התקנה

```bash
# התקנת תלויות
npm install

# הרצת שרת פיתוח
npm run dev
```

האפליקציה תרוץ על `http://localhost:3000`

### בנייה לייצור

```bash
npm run build
npm start
```

## מבנה הפרויקט

```
SkillSwap/
├── app/                    # Next.js App Router
│   ├── auth/              # דף התחברות/הרשמה
│   ├── profile/           # פרופיל משתמש
│   ├── matches/          # התאמות ושיעורים
│   ├── chat/             # מערכת צ'אט
│   └── schedule/         # קביעת שיעורים
├── components/            # רכיבים משותפים
├── lib/                  # לוגיקה וכלי עזר
│   ├── store.ts         # Zustand store
│   ├── ai-matching.ts   # לוגיקת התאמות AI
│   └── storage.ts       # Local Storage helpers
├── types/                # TypeScript types
└── public/              # קבצים סטטיים
```

## שימוש

### יצירת חשבון
1. הירשם עם שם, אימייל וסיסמה
2. השלם את הפרופיל:
   - הוסף מיומנויות שאתה יודע ללמד
   - הוסף מיומנויות שאתה רוצה ללמוד
   - בחר העדפות (מיקום, סוג שיעור)

### מציאת התאמות
1. עבור לדף "מצא התאמות"
2. המערכת תציג התאמות פוטנציאליות
3. קבל או דחה התאמות
4. התאמות מקובלות יופיעו בדף "ההתאמות שלי"

### תקשורת ושיעורים
1. פתח צ'אט עם התאמה מקובלת
2. קבע שיעור דרך כפתור "קבע שיעור"
3. לאחר השיעור, דרג את המורה

## אחסון נתונים

כרגע האפליקציה משתמשת ב-Local Storage לאחסון נתונים (MVP).

## AI Integration

- שילוב OpenAI API / Anthropic API
- שיפור אלגוריתם ההתאמות
- יצירת תוכניות לימוד מותאמות אישית
